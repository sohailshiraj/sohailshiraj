## 🧭 A few things I believe about software

1. **Accessibility is part of the feature.** It's not a ticket you open after launch.
2. **Boring tech is a feature.** Save the excitement for the problem, not the infrastructure.
3. **The best bug report is the one I filed myself** before a user ever noticed.
4. **Code review is mentorship.** It goes both ways, every time.
5. **Curiosity compounds.** Most of what I know came from building something nobody asked me to build.
